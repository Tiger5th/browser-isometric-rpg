# P2 第一批：游戏体验（Gameplay & Feel）规格

日期：2026-10-17。来源：P1 人工验收反馈 + grilling 会话（共 26 个决策，记录在会话与 map.md）。

## Problem Statement

P1 垂直切片技术闭环已验收（13/13 环节、60fps、预算全绿），但项目所有者实际游玩后体验糟糕：

- 战斗**没有反馈**：打史莱姆时它没有血条、没有受击表现、没有伤害数字、没有音效——玩家不知道自己在战斗。
- 调试工具（P0Harness 面板）常驻正式场景左上角，碍事。
- 环境件是 billboard 平面，可以**穿模**（穿过树/墙/桶），世界没有物理实感。
- 地图边界外是黑色虚无，不像一个真实世界。
- 对话交互不合逻辑：远处点 NPC 立即弹对话框；玩家与 NPC 没有面对面。
- NPC 没有独立形象：占位建模 + 共用贴图，无立绘，角色没有辨识度。
- 只有普攻点按，战斗没有操作深度。

## Solution

P2 第一批四张票，从「能玩」升级到「好玩、好看、有实感」：

1. **战斗反馈层 + 第一个主动技能（重击）**：把 GameSession 结算事实转译为视觉+听觉信号（飘字/血条/受击/音效/前摇/顿帧震屏/升级时刻），并加一个带冷却的重击技能作为反馈基建的第一个完整消费者。
2. **世界质感**：环境件网格化 + 硬碰撞（不可穿模）、灌木保留可穿（预留草丛机制）、边界外景观环带消除黑色虚无、统一主光与暖色氛围、NPC 待机行为。
3. **对话与 NPC 体验**：两段式对话交互（点击寻路 → 头顶气泡按钮 → 点击才开）、面对面转向、galgame 式全屏立绘（说话方亮）、NPC 独立建模贴图 + 角色色板卡管线、对话镜头推近压暗。
4. **真实角色接入**：VRM（Booth 免费高精度）→ Blender 脚本换贴图/绑骨 → Mixamo 重定向；agent 负责 Blender 安装、VRM 挑选下载、风格锚定生图（角色色板卡 + NPC 立绘 + 远景样本）。

四张票完成后进入 P2 主体（故事小章节 + 战斗深度 + 探索回报，另行拆票）。

## User Stories

### 战斗反馈层（票 27）

1. As a 玩家, I want 我攻击敌人命中时敌人头顶弹出伤害数字并上飘淡出, so that 我确切知道每一刀打中了、打了多少。
2. As a 玩家, I want 敌人攻击我时我也看到红色伤害数字 + HUD 血条动画 + 屏幕边缘闪红, so that 我知道自己正在挨打、情况多危险。
3. As a 玩家, I want 被我选中的敌人脚下有目标圈且血条常显, so that 我知道自己在打谁。
4. As a 玩家, I want 未被选中的敌人血条只在受击后显示、5 秒无伤淡出, so that 屏幕干净不闹。
5. As a 玩家, I want 敌人受击时闪白 + 轻微击退抖动, so that 攻击有打击实感。
6. As a 玩家, I want 敌人攻击前有明显前摇提示（抬手/变色约 0.3 秒）, so that 我有走位躲避的空间。
7. As a 玩家, I want 命中瞬间有顿帧 + 轻微镜头震动, so that 重击有分量。
8. As a 玩家, I want 敌人死亡时消散动画 + 掉落/经验飘字, so that 击杀有完成感。
9. As a 玩家, I want 我升级时全屏金光 + 音效 + 属性变化飘字, so that 成长里程碑被清晰地庆祝。
10. As a 玩家, I want 普攻命中/受击/击杀/拾取/升级/UI 点击有音效, so that 游戏不是哑巴。
11. As a 玩家, I want 一个「重击」主动技能（约 8 秒冷却、1.5 倍伤害、更长前摇、独立音效与更大飘字）, so that 战斗有操作深度而不只是点按。
12. As a 玩家, I want 重击技能按钮在 HUD 上显示冷却转圈, so that 我知道技能什么时候能用。
13. As a 玩家, I want 攻击冷却中点击地面时移动指令打断攻击意图（走 A）, so that 我可以 hit-and-run 风筝敌人。
14. As a 玩家, I want 角色攻击时转向目标, so that 战斗方向感正确。

### 世界质感（票 28）

15. As a 玩家, I want 树/石墙/木桶/木箱是真正的 3D 网格且不可穿过, so that 世界有物理实感、不再穿模。
16. As a 玩家, I want 灌木可以穿过, so that 走路不被无意义的障碍打断。
17. As a 玩家, I want 灌木进入时角色被轻微遮挡/半透明, so that 藏进草丛有视觉反馈（为草丛机制预留）。
18. As a 玩家, I want 地图边界外有低细节景观环带（山/远景树/雾）渐暗过渡, so that 世界不再被黑色虚无包围。
19. As a 玩家, I want 全场景统一主光方向（左上 45°）与暖色明亮氛围、暗部紫灰, so that 画面像一个被统一美术指导过的整体。
20. As a 玩家, I want NPC 有待机行为（呼吸摆动/偶尔转身踱步）, so that 世界是活的。
21. As a 玩家, I want 网格化后的场景仍满足性能预算（≥59.5fps、draw calls ≤350）, so that 质感提升不以帧率为代价。

### 对话与 NPC 体验（票 29）

22. As a 玩家, I want 点击远处 NPC 时角色自动寻路走到 NPC 面前但不弹对话框, so that 交互有合理的空间逻辑。
23. As a 玩家, I want 到达 NPC 面前时 NPC 头顶出现「对话」气泡按钮（有可接任务时是感叹号）, so that 对话由我主动触发、不会误开。
24. As a 玩家, I want 点击气泡才进入对话, so that 对话节奏由我控制。
25. As a 玩家, I want 对话开始时玩家与 NPC 互相转向面对面, so that 演出符合常识。
26. As a 玩家, I want 对话时屏幕两侧立起角色全屏立绘（说话方亮、听话方微暗）, so that 我能看到角色的动作神情（galgame 式）。
27. As a 玩家, I want 对话框与立绘有二次元标准风格（半透明深底、角色主色边、名字牌角色主色）, so that 演出有品质感。
28. As a 玩家, I want 对话开始时镜头轻推近双方 + 背景轻微压暗, so that 对话有沉浸感。
29. As a 玩家, I want 每个 NPC 有独立建模与独立贴图（按角色色板卡生成）, so that 角色有辨识度。
30. As a 玩家, I want 立绘与角色 3D 贴图同源（同一色板卡生成）, so that 画风与配色不漂移。
31. As a 玩家, I want 对话进行中点击地面移动可以打断/离开对话范围则结束对话, so that 我不会被对话锁死。

### 真实角色接入（票 30）

32. As a 玩家, I want 玩家角色是真实 VRM 模型（Booth 高精度免费）而非占位 glb, so that 主角有正式形象。
33. As a 玩家, I want 角色有 Mixamo 重定向的行走/奔跑/攻击动作, so that 动作不再是滑步占位。
34. As a 项目所有者, I want agent 自动完成 Blender 安装验证、VRM 挑选下载、换贴图/绑骨脚本化处理, so that 我不需要亲手做工具链环节。
35. As a 玩家, I want 角色 toon 渲染 + 描边在真实 VRM 上正常工作（morph 眨眼可见）, so that 真实资产不破坏既有风格。

### 全局

36. As a 玩家, I want 正式游玩入口默认不显示 P0Harness 面板, so that 画面干净（`?harness=1` 才显示）。
37. As a 开发者, I want 伤害/命中/死亡/治疗升级为 GameSession 一等订阅事件, so that 反馈层、音效系统、未来回放共用同一条事件流。

## Implementation Decisions

### 事件架构（票 27 地基）

- GameSession 新增一等订阅事件（复用 `game-events.ts` 的 subscribe 通道，与 `enemy-killed` 同级）：`damage-dealt`（攻击者/目标/数值/是否重击/是否击杀前最后一击）、`health-changed`、`player-level-up`、`item-gained`。`drainEvents()` 战斗日志保留不废弃。
- 表现层反馈系统（飘字/血条/音效/顿帧）**只消费事件**，不得读会话内部状态——反馈层的定义：把结算事实转译为视听信号，不改变游戏状态（已写入 GLOSSARY）。
- 重击 = GameSession 新意图 `heavyAttack`（复用 attack 结算器，倍率 1.5、冷却 8000ms 走属性系统），快照版本 v2→v3（冷却剩余时间需进快照），迁移链补 v2→v3。

### 交互规则（票 27/29）

- 走 A：移动指令永远打断攻击意图（英雄联盟语义）；攻击朝向 = 结算时面向目标。
- 两段式对话：点击 NPC = moveTo 到对话距离（约 1.5m）→ 到达后 NPC 头顶浮现气泡按钮（`对话`/有可接任务时 `!`）→ 点击气泡 → 双方互转面对面 → 对话开启。距离内点击 NPC 直接出气泡不弹对话。对话中玩家移动意图 = 结束对话。
- 对话镜头：推近 + 压暗在表现层实现，只动相机与后处理参数，不进逻辑层。

### 世界表现（票 28）

- 环境件网格化范围：树/石墙/木桶/木箱 4 类 → 程序化几何拼装（Babylon 内置几何组合）+ 现有 Gemini 贴图，挂 collider（moveWithCollisions + navmesh 排除）；灌木保留 billboard 可穿。CC0 低模包（Kenney/quaternius）为观感不达标时的后备。
- 碰撞：树/墙/桶/箱硬碰撞（完全挡住）；灌木无碰撞。玩家与敌人路径层逻辑不变（navmesh 已排除障碍）。
- 边界景观环带：固定一圈低细节景观网格 + 渐暗雾，风格进锚定图（agent 用 ego-browser 生成「远景/天际线」样本）；程序化远景（Node Geometry 大范围低模地形）推到 P2 后期。
- 光照：全场唯一主光（左上 45°），暗部用锚定图紫灰色调（不用纯黑），ImageProcessing 色调分级（明亮暖色基调）。
- 性能护栏：网格化 + 环带后重跑 L5 预算（fps ≥59.5、drawCalls ≤350），LOD 逐件最低配置。

### 资产管线（票 29/30）

- **角色色板卡**：每个主要角色一张（主色/辅色/点缀色 + 发色服装关键词），3D 贴图、立绘、头像全部同卡生成。agent 用 ego-browser 按 Gemini 生图工作流产出。
- 立绘：galgame 式全屏，屏幕左右两侧，说话方亮/听话方微暗；每 NPC 一张基础立绘（表情差分推 P2 主体按角色分级）。立绘摆放在表现层，与 quest-loop-ui 集成。
- NPC 独立化范围：主角 + NPC 用 VRM/独立贴图；敌人占位模型统一贴图（精英怪推 P2 主体）。
- VRM 管线（票 30）：Booth 免费高精度 VRM（agent 挑选下载，注意许可证只允许自用）→ Blender（agent 安装 + 脚本化：换贴图/绑骨）→ Mixamo 重定向（walk/run/attack）→ 既有 VRM→GLB 工具 → toon 渲染 + morph 验证。此票顺路完成 P0 遗留的 Blender headless 导出补测（`npm run assets:blender:repro`）。

### 全局

- Harness 面板：`p1-world` 等正式场景默认不挂 Harness DOM，`?harness=1` 显式开启；调试 API（`window.P0Harness*`）不受影响（ego-browser 冒烟依赖它）。此条不占票，随票 27 的场景改动直接落地。
- 音效：公有领域/CC0（freesound.org CC0 过滤，agent 挑选下载），落 `assets/audio/`；播放由事件驱动（反馈层内），首次交互后解锁 AudioContext。

## Testing Decisions

- 只测外部行为：L1 断言意图/事件的输出（重击伤害倍率、冷却、快照往返、事件序列），不断言内部结算实现。
- **L1**（vitest，既有接缝）：重击意图、新战斗事件、快照 v3 迁移链——先例 `game-session-combat.test.ts` / `game-session-save.test.ts`。
- **L2**（content:lint，既有接缝）：schema 扩展（技能数据、NPC 立绘引用、色板卡）负向测试——先例 `lint-negative-test`。
- **L4**（ego-browser，既有接缝）：p1-world 冒烟扩展——重击全流程（冷却/飘字/HUD）、两段式对话（点击→气泡→点击→立绘）、网格化后移动不被树挡死且灌木可穿、存读档后冷却恢复。报告 JSON 落 `reports/`，截图落 `artifacts/`。
- **L5**（既有 measure 接缝）：网格化 + 景观环带后预算复测（fps/drawCalls/heap），共享浏览器 p95 只报告不阻塞——先例 `reports/p1-world.json`。
- 音效不做自动化断言（浏览器自动播放策略干扰），人工验收清单加一条。

## Out of Scope

- P2 主体内容：故事小章节、更多敌人行为差异化、更多技能/资源系统、探索回报（宝箱/资源点）、新手引导、小地图——后续拆票。
- 草丛机制本体（潜行/视野判定）——本批只做灌木可穿与视觉预留。
- 表情差分立绘、程序化远景地形、移动端适配、Safari/KTX2 复测、生产构建 Lighthouse。
- 敌人精英化与独立建模。
