# P2 第二批：品质感与动力切片（存档/主界面/等级/相机/NPC 行为/区域 2/经济）规格

日期：2026-10-17。来源：P2 第一批规格后的补充 grilling 会话（18 个决策，Q1–Q18，记录在会话与 map.md）。

## Problem Statement

P2 第一批（票 27–30）解决「手感」，但项目所有者指出 P2 作为决定游玩体验的批次还欠完善：

- **存档不像个存档系统**：单槽手动存档、无自动存档；等级/经验根本不在快照里（xp 只活在战斗日志事件流，读档后累计经验丢失）；没有选槽读档界面。
- **没有主界面**：打开网页直接魂穿进世界，没有标题画面、没有继续游戏/新游戏、没有开屏演出——第一印象是「技术 demo」。
- **动作动效单薄**：主角只有 walk/idle 两态切换，无 run/attack/受击/死亡；敌人零动画。
- **角色太少**：NPC 只有 2 个，敌人 3 种全是史莱姆换色；没有可交互物件，走路只遇到敌人和 NPC。
- **没有玩下去的理由**：无探索回报、无经济闭环、无收集目标——「然后呢」的问题。
- **NPC 站桩**：NPC 永远站在原地，世界是死的。
- **相机锁死**：不能缩放旋转，无法欣赏角色。

## Solution

P2 第二批七张票（31–37），与第一批 27–30 并行衔接：

1. **存档系统 2.0 + 等级正式化**（票 31）：自动存档（关键节点+退出兜底）+ 3 手动槽 + 选槽主菜单 UI + 等级/经验入快照。
2. **主界面与开屏**（票 32）：标题画面（logo + 氛围图 + logo 演出动画）+ 继续游戏/新游戏 + 黑场过场衔接。
3. **村庄聚点与经济**（票 33）：3–4 NPC 聚点（安全区）+ 商人真实买卖（最小闭环经济）+ NPC 行为逻辑（巡逻路线 + 任务完成换位）。
4. **等级系统本体**（票 34）：经验阈值曲线 + 升级加属性（供票 27 升级金光与新内容挂靠）。
5. **第二区域与联动**（票 35）：小型第二区域（史莱姆巢穴）+ 传送连接 + 跨区域任务。
6. **两种新敌人 AI**（票 36）：近战冲锋型（可走位躲）+ 远程吐弹型（逼玩家接近）。
7. **探索回报**（票 37）：宝箱 3–5 个 + 收集品计数（萤光草）+ 全收集饰品奖励 + 相机自由化（缩放旋转全解锁 + 欣赏模式一键复位）。

## User Stories

### 存档系统 2.0（票 31）

1. As a 玩家, I want 游戏在区域切换/任务状态变化/获得重要物品时自动存档, so that 我不会因为忘记存档而丢进度。
2. As a 玩家, I want 关闭页面时进度被兜底保存, so that 意外退出也不丢档。
3. As a 玩家, I want 有 3 个手动存档槽 + 1 个自动槽, so that 我可以保留多个进度点。
4. As a 玩家, I want 选槽界面显示每个槽的存档时间/游戏时长/角色等级, so that 我知道哪个槽是哪个进度。
5. As a 玩家, I want 读档后我的累计经验不丢失, so that 升级进度是连续的（修复现存缺口）。
6. As a 玩家, I want 以后新增的系统字段自动得到默认值而不需要我手动迁移, so that 老档永远能读。

### 主界面与开屏（票 32）

7. As a 玩家, I want 打开游戏先看到标题画面（游戏 logo + 氛围背景 + 版本号）, so that 第一印象像一个正经游戏。
8. As a 玩家, I want 标题画面有继续游戏（有档时）/新游戏两个入口, so that 我能选择进入方式。
9. As a 玩家, I want 标题字有浮现演出（淡入/粒子或雾气）, so that 开屏有仪式感。
10. As a 玩家, I want 从主界面进入游戏时黑场过场衔接, so that 转场不生硬。
11. As a 玩家, I want 新游戏前若已有自动档有确认提示, so that 不会误覆盖进度。

### 村庄聚点与经济（票 33）

12. As a 玩家, I want 村庄是安全区（敌人不进入）, so that 有喘息与整备的空间感。
13. As a 玩家, I want 商人 NPC 可以卖掉战利品（史莱姆凝胶）并购买治疗草药, so that 金币有意义、打怪有回报。
14. As a 玩家, I want NPC 有自己的巡逻路线（走走停停、到点张望）而非站桩, so that 世界是活的。
15. As a 玩家, I want 对话时 NPC 停下面向我、结束后继续巡逻, so that 交互自然。
16. As a 玩家, I want 完成关键任务后 NPC 换到新位置（如马婆婆任务后到村口）, so that 世界因我而变。
17. As a 玩家, I want 聚点有 3–4 个独立形象的 NPC（色板卡管线）, so that 村庄有角色阵容。

### 等级系统（票 34）

18. As a 玩家, I want 有明确的经验升级曲线（等级越高所需越多）, so that 成长节拍可感知。
19. As a 玩家, I want 升级时属性提升（攻击/防御/HP）, so that 变强是真实的。
20. As a 玩家, I want 等级显示在 HUD 与存档槽信息里, so that 成长随时可见。

### 第二区域与联动（票 35）

21. As a 玩家, I want 一条路通往第二个小型区域（史莱姆巢穴）, so that 世界有纵深。
22. As a 玩家, I want 区域间切换有黑场过场, so that 移动到新区域自然。
23. As a 玩家, I want 有跨区域任务（马婆婆让我去巢穴杀新怪）, so that 地图之间有联动。
24. As a 玩家, I want 区域 2 有专属掉落物, so that 探索新地图有独特回报。

### 新敌人 AI（票 36）

25. As a 玩家, I want 一种会蓄力冲锋的近战敌人, 前摇明显且可走位躲开, so that 走位有意义。
26. As a 玩家, I want 一种远程吐弹敌人会保持距离攻击, so that 我必须主动接近、战斗有压力差。
27. As a 玩家, I want 两种新敌人有独立外形贴图, so that 敌人有辨识度。

### 探索回报与相机（票 37）

28. As a 玩家, I want 地图上散落 3–5 个可开启宝箱（含区域 2）, so that 探索有惊喜。
29. As a 玩家, I want 收集品（萤光草）散落并有 HUD 计数, so that 我有收集目标。
30. As a 玩家, I want 全收集后获得一件饰品奖励, so that 收集有句号。
31. As a 玩家, I want 宝箱开启状态与收集进度存档, so that 读档不回退。
32. As a 玩家, I want 相机可滚轮缩放与旋转, so that 我可以自由观察世界。
33. As a 玩家, I want 一键回到默认等距视角（欣赏模式复位）, so that 玩累了随时回到标准构图。
34. As a 玩家, I want 死亡有轻惩罚（回村复活 + 掉少量金币）, so that 战斗有张力。

## Implementation Decisions

### 存档系统 2.0（票 31）

- 快照 v2→v3（与票 27 重击冷却合流为同一次升版）：新增 playerLevel/cumulativeXp（修复 xp 不入档缺口）、worldState 通用容器（`Record<string, JsonValue>`，宝箱开启/收集计数/门机关等一切世界状态挂这里，以后加系统不再升大版本——Q6 宽松口径）、NPC 实时位置（entities.position 天然覆盖，无新字段）、槽位元数据（存档时间/游戏时长/等级）独立于快照存槽位侧。
- 迁移链补 v2→v3：新字段全默认值；迁移链模式（SaveMigrationRegistry 逐版本 +1）不变。
- 存储：IndexedDB store `saves` 由单 key 扩为槽位 keys（`auto`、`slot-1..3`），SaveStorage 适配器接口不变（实现层扩展）。
- 自动存档时机：区域切换 + 任务状态变化 + 获得重要物品（宝箱/任务奖励）触发写 `auto` 槽；`beforeunload` 兜底同步写（IndexedDB 在 unload 内可行）。定时器不做。
- 等级正式化：经验阈值曲线进 content（每级一行：阈值 + 属性加成，数据驱动）；升级由 GameSession 在 xp 入账时结算并发射 `player-level-up` 事件（票 27 已定义该事件，此处为它的逻辑层生产者）。
- 选槽 UI：主菜单形态（票 32 提供容器），槽位列表 + 元数据 + 读/写/删除。

### 主界面与开屏（票 32）

- 标题画面为 DOM/CSS 层（复用 loadingGate 的黑场基建），logo 用 Gemini 生图（风格锚定同源），游戏名暂用工作代号占位（正式名后换图，用户 Q12 决策：先不考虑命名）。
- 入口逻辑：有 `auto` 或任一手动槽存档 → 显示「继续游戏」（读自动槽或让用户选槽）；「新游戏」在存在任意存档时二次确认。
- logo 演出：标题字淡入 + 雾气/粒子（CSS/轻量 canvas），一次性入场动画，时长 2–3 秒可跳过。
- 设置页不做（无设置实体项）；音量静音按钮随票 27 音效在 HUD 先行。

### 村庄聚点与经济（票 33）

- 安全区 = 区域内矩形/圆形地带，敌人 AI 意图进入时被逻辑层拒止（不追入）。
- 商人 = NPC 新行为类型，对话进入交易 UI（列表：卖出价/买入价，复用 item 系统与金币）；价格表进 content schema（npc 扩展 vendor 字段）。
- NPC 行为逻辑（Q13 A + 例外）：每 NPC 一条巡逻路线（点位列表，walk 到点 → 停留张望 → 下一点），纯表现层驱动（消费快照渲染，不进逻辑层移动意图——NPC 位置仍由逻辑层快照携带）；对话/任务交互时暂停面向玩家，结束后继续。例外：任务状态变化时逻辑层下发一次「换锚点」事件，NPC 走到新锚点（世界因你而变的最小实现）。
- NPC 实时位置进快照（Q14 A）：entities.position 已有，巡逻进度（当前点位索引）补进 EntitySnapshot 可选字段。
- 内容：新增 2 NPC（商人 + 氛围/伏笔位），马婆婆/林斥候保留并配巡逻路线；色板卡由票 29 管线产出。

### 等级系统（票 34）

- 曲线初版：L2=100、L3=250、L4=450、每级 +250 递增（content 数据，可调）；每级 +2 攻击 +2 防御 +10 maxHp（修饰器入账）。
- HUD 等级徽标（票 24 HUD 扩展）。

### 第二区域与联动（票 35）

- 区域 2「史莱姆巢穴」：小型（约主区域 1/3），传送点/路口连接（走到底触发区域切换 + 黑场过场，复用 loadingGate）；用既有区域数据结构与流式加载地基，无新引擎机制。
- 联动形态：跨区域任务 1 条（kill 新怪 in region 2）+ 区域 2 专属掉落物（供票 33 商人交易）；探索度百分比/动态联动推后。
- 区域 2 敌人配置：票 36 两种新敌人 + 既有史莱姆混编。

### 新敌人 AI（票 36）

- 冲锋型：状态机在 chase 后加 windup（明显前摇 0.6s，配合票 27 前摇提示）→ charge（直线高速，路径上命中判定一次）→ recovery（硬直，走位躲开后可白打）；冲锋可被硬碰撞挡停。
- 吐弹型：保持攻击距离 kiting（玩家接近则后撤），投射物为逻辑层实体（位置/速度/命中判定在 GameSession，表现层只渲染）。
- 敌人模板扩展：aiProfile 字段（chaser/slugger/windup-charge/ranged-kite）进 enemy-templates schema。
- 独立贴图：新敌人各一张 Gemini 贴图（色板卡管线顺路）。

### 探索回报与相机（票 37）

- 宝箱：世界实体新类型（content 定义 position/loot 表），开启 = 交互意图 → loot 入包 + worldState 记录开启状态；一次性。
- 收集品：萤光草 = 现有 item 系统定义（拾取即计数，无新系统），计数 = worldState 聚合；HUD 计数条目；全收集奖励 = 一件饰品（修饰器），自动入包。
- 相机（Q16 C）：滚轮缩放（有限范围）+ 右键/中键拖拽旋转；预设系统——出厂等距预设（alpha/beta/radius 常量）+ 欣赏模式一键复位（平滑插值回预设，快捷键 + HUD 按钮）；预设位结构支持将来加多个。
- 死亡轻惩罚：复活改为回村出生点 + 扣 10% 金币（向上取整，无金币则无惩罚）。

### 全局

- 所有 content 扩展（vendor 价格表、等级曲线、宝箱、收集品、区域 2、新敌人、新 NPC）都走既有 content schema + content:lint 接缝；L2 负向测试同步扩。
- 票 31 与票 27 的快照升版合流：v3 一次升版装下重击冷却 + 等级/经验 + worldState；两票先后落地时后落地的消费先落地者的 v3（避免双迁移）。

## Testing Decisions

- 只测外部行为；全部复用既有接缝，零新增接缝。
- **L1**（vitest）：快照 v3 往返 + 迁移链 v2→v3（含 worldState 透传）、自动存档触发条件、等级结算（xp→升级→属性/事件）、冲锋/吐弹 AI 状态机与投射物命中、宝箱/收集的 worldState 读写、安全区拒止、死亡惩罚。先例 `game-session-combat.test.ts` / `game-session-save.test.ts` / `validate.test.ts`。
- **L2**（content:lint）：新 schema 字段（vendor/aiProfile/等级曲线/宝箱/收集品/区域 2/新 NPC）正负向。先例 `lint-negative-test` / `validate.test.ts` 负向组。
- **L4**（ego-browser）：标题画面入口流（继续/新游戏/确认）、选槽读写删、自动存档触发、商人买卖闭环、NPC 巡逻与任务后换位、区域 2 往返 + 跨区域任务、两种新敌人战斗、宝箱开启/收集计数/全收集奖励、相机缩放旋转与一键复位、死亡惩罚。报告 JSON 落 `reports/`、截图落 `artifacts/`。
- **L5**：区域 2 + 新实体后预算复测（fps ≥59.5、drawCalls ≤350、heap）；p95 只报告。
- 音效/演出动画不做自动化断言，人工验收清单加条目。

## Out of Scope

- 昼夜循环与 NPC 作息日程（Q13 C）。
- 设置页（音量滑条/画质档 UI）——HUD 静音按钮先行。
- 正式游戏名与 logo 终稿（占位代号图）。
- 立绘表情差分、任务系统本体扩展（仍为 offer/turnin 标签模式）、剧情章节。
- 程序化远景地形、探索度百分比、区域动态联动（清巢停刷）、小地图、新手引导系统（借林斥候对话软引导）。
- 多存档云同步、导出导入存档文件。
