# ADR-0004: 对话采用 Ink；RPG 系统自研，数据驱动 + EntityId + 修饰器

日期：2026-10-17　状态：已接受

## 决策

对话运行时采用 Ink（inkjs，MIT）。任务/背包/装备/存档/敌人行为决策自研，统一在 EntityId + 修饰器的数据驱动模型上。存档 = IndexedDB（idb 封装）+ 版本迁移链。敌人 AI 决策从状态机起步，P3 引入行为树。

## 理由

- 调研确认开源参考（RPG-JS 等）均为 demo 质量，「开源直接采用」不成立。
- 数据驱动 + 统一修饰器：装备/任务/buff 共用一套机制；状态天然可序列化；内容 = 纯数据，可由 AI Agent 批量生产。
- Ink 是业界最成熟叙事语言，数据格式无引擎绑定；inkjs 为个人维护移植是已知风险（P0 验证项 7）。
- 存档兼容是长期命脉，迁移链从第一天建立。

## 代价

- 自研范围大（五个子系统），按 P0→P1 渐进交付控制风险。
- 修饰器 schema 冻结前必须完成 P0 表达力验证；之后任何变更走迁移链 + 新 ADR。
