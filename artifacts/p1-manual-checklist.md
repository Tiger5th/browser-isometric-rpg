# P1 人工验收清单（约 10 分钟）

目标：亲手走一遍 P1 的完整闭环，确认「点击移动 → 战斗 → 对话 → 任务 → 背包/装备 → 存读档」不崩、手感成立。

## 0. 启动（约 1 分钟）

```bash
npm ci
npm run dev
```

浏览器打开终端里打印的地址，加上场景参数（默认端口通常是 5173）：

```
http://localhost:5173/?scenario=p1-world&quality=auto
```

- 推荐 Chrome / Edge，窗口约 1450×826 或更大，DPR 2 也可以。
- 等待加载完成：右侧出现 HUD（HP/经验/攻击/防御），画面是翠谷贴图环境 + 卡通描边角色。
- 如果之前玩过，先点 HUD 的 **「删除存档」**，再按 `Cmd+R` / `Ctrl+R` 刷新，确保从全新会话开始。

## 1. 清档与初始状态（30 秒）

- 操作：删除存档 → 刷新页面。
- 预期：
  - HUD：`HP 100 / 100`、`经验 0 / 100`、`攻击 12`、`防御 4`。
  - 任务栏：显示「暂无进行中的任务。去和马婆婆聊聊吧。」
  - 场景里有 3 只史莱姆。
  - 右下角状态：`无存档：点击「存档」创建`。

## 2. 点击移动 + 对话接任务（1 分钟）

- 操作 A：点击地面空地。角色应平滑走过去（约 5.5 米/秒），不会穿模或抖动。
- 操作 B：点击紫衣 NPC **马婆婆**（约在地图中央偏右）。弹出对话面板。
- 操作 C：选择「发生了什么？」或「我这就去。」。
- 预期：对话关闭，HUD 任务栏出现 **「清理史莱姆 · 进行中 · 击杀翠谷史莱姆 0/3」**。

## 3. 战斗 + 掉落（2–3 分钟）

- 操作：**直接点击一只史莱姆**（不是点 HUD 的调试按钮）。角色会自动走近并每约 1 秒攻击一次。
- 预期：
  - 史莱姆头顶/血条方向有受击反馈，血量下降；敌人也会反击，玩家 HP 会掉。
  - 击杀 3 只后，任务变为 **「可交付 · 3/3」**。
  - 打开背包应看到 **史莱姆凝胶 ×3 左右**；经验变为 30。
- 小提示：三只一起围上来时掉血较快，这是当前首版数值，属正常。若角色死亡，会回出生点满血复活，已击杀的敌人不会刷新，任务进度保留。
- 备选：如果点击敌人没有反应，可用 HUD 最下方的「调试：攻击最近的史莱姆（走真实战斗）」按钮——但正常路径应当是点击敌人本体。

## 4. 交任务 + 奖励（30 秒）

- 操作：走回/点击马婆婆，选择「（复命）史莱姆已经清理完了。」。
- 预期：
  - 任务状态 **已完成**。
  - HUD 最大 HP 从 100 变为 **110**。
  - 背包新增 **旅人短剑 ×1**、**疗伤草 ×2**。

## 5. 背包 / 装备 / 消耗品（1 分钟）

- 操作：点 HUD 的 **「背包 (I)」**（或按 `I`）。
- 预期：面板列出 3 组物品；顶部三个槽位：武器 / 护甲 / 饰品。
- 操作 A：点旅人短剑右侧的 **「装备」**。
  - 预期：HUD **攻击 12 → 17**；武器槽显示「旅人短剑 · attack +5」；按钮变为「卸下」。
- 操作 B：点疗伤草右侧的 **「使用」**。
  - 预期：HP 立即 +30（不超过 110），疗伤草数量 2 → 1。
- 操作 C（可选）：按 `I` 或 `Esc` 关闭面板，再按 `I` 打开，确认开关正常。

## 6. 手动存档 → 刷新 → 自动读档（1 分钟，最关键）

- 操作 A：点 HUD 的 **「存档」**。
  - 预期：右下角状态变绿：`已存档 · v… · …ms`。
- 操作 B：按 `Cmd+R` / `Ctrl+R` 刷新页面，等待加载完成。
  - 预期：
    - 状态显示 `已从存档恢复 · v… · …ms`。
    - 角色回到存档时的位置，HP / 最大 HP / 攻击 / 经验与存档前一致。
    - 任务仍是「已完成 3/3」。
    - 背包仍是原来的物品与数量；短剑仍处于已装备状态（攻击 17）。
    - 三只史莱姆仍是死亡状态。
- 操作 C：读档后再用一次剩下的疗伤草，或点击地面走两步。
  - 预期：一切操作正常，说明读档后游戏仍可继续玩。

## 7. 画质档位（可选，30 秒）

依次打开：

```
http://localhost:5173/?scenario=p1-world&quality=high
http://localhost:5173/?scenario=p1-world&quality=medium
http://localhost:5173/?scenario=p1-world&quality=low
```

预期：三种档位都能正常渲染；`low/medium` 会关闭部分描边/分级或降低渲染比例。默认 `auto` 会按帧率自动调节分辨率。

## 8. 验收判定

全部完成且没有崩溃、黑屏、卡死、状态错乱，即视为人工验收通过。若发现问题，请记录：

- 哪一步、点了什么；
- 当时的 HUD 数字 / 截图；
- 浏览器控制台报错（F12 → Console）。

## 已知问题（不是本次验收的阻塞项）

| 问题 | 说明 |
|---|---|
| 占位角色 | 当前主角是程序化占位角色（有走路/奔跑/眨眼），不是最终 VRoid 美术 |
| VRM 链路 | 真实 VRoid/VRM 资产尚未接入；转换器与接入点已就绪 |
| 布局数据 | 区域布局暂在渲染层常量里，尚未进 `content/`（P2 再提升） |
| p95 帧时间 | 共享浏览器下 p95 约 17.5–20ms，略高于 17ms 目标；平均 60fps、draw calls 35、内存 99MB 均达标 |
| 自动存档 | 只有手动存档 + 打开页面自动读档，没有定时自动存档 |
| 战斗数值 | 首版数值，三只围攻时掉血明显；死亡会满血复活且不刷新已死敌人 |
| 复命台词 | 交任务时仍会显示开场白，属 ink 结构的小瑕疵，不影响任务 |
| 移动端/Safari | 未适配/未复测；推荐桌面 Chrome/Edge + WebGL2 |
| 音频/成就/技能树 | P1 范围外，未实现 |
